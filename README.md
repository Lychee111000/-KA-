# 知行 · KA 销售复习室

一个围绕 **市场调研与 KA 大客户开发** 的离线复习工具。把课程笔记按模块和小节组织起来，让你在阅读知识点的同时记便签、标记学习进度，再通过闪卡、自测和口述训练检查理解。

**纯前端 · 无需安装依赖 · 离线使用 · 蓝色界面 · 笔记保存在自己的浏览器**

下载整个仓库并解压，双击 [`index.html`](./index.html) 即可开始。没有账号注册、后端服务或构建步骤，也不需要安装 Node.js、Python 或其他运行环境。

> 当前课程范围：S1–S3，更新至 11-24 第三课的「做进去 → 站稳 → 复制 → 增量」。配套 PPT 仅取 01–03 章，后续课程未纳入。完整来源见 [课程原文](./课程原文.md)。

## 快速开始

### 不写代码，下载就用

1. 在仓库首页点击 **Code → Download ZIP**，下载整个仓库。
2. **完整解压**到一个准备长期保留的文件夹。
3. 找到 `index.html`，双击并使用 Chrome 或 Edge 打开。
4. 从「知识地图」选择章节，开始阅读、记笔记和练习。

请完整保留同目录中的 `style.css`、`app.js` 和 `data.js`。**仅下载 `index.html` 不够**：它需要同目录的样式、交互脚本与课程数据。

不要在压缩包内部直接双击使用，也不要把 GitHub 的源码预览页当成实际应用。第一次打开后即可断网复习；运行时不请求 CDN、在线字体或远程课程接口。

### 已经拿到别人发来的文件夹

无需重新下载。确认四个运行文件在同一目录，直接双击 `index.html`。如果浏览器显示的是代码，请右键文件，选择「打开方式」，再选浏览器。

## 课程结构

当前内置 **8 个模块、40 个课程小节、29 个术语、20 道自测题、5 道综合口述练习**。

学习主线：

```text
看清市场：容量估算 + 竞品对标
    ↓
进入市场：0→1 路径 + 客户三角 + 三方推进
    ↓
拿下 KA：识别客户 + 四步法 + 四道关
    ↓
经营客户：站稳 → 复制 → 借资源拓展 → 增量
    ↓
说清价值：方式 → 结论 → 价值
```

| 模块 | 核心内容 | 复习时要回答的问题 |
| --- | --- | --- |
| 0 综合输出 | 五项交付物、表达外壳、五套答题骨架 | 做了什么，形成什么结论，有什么价值？ |
| 1 市场容量估算 | 三条测算路径、客户口径、交叉验证、容量用途 | 如何估算量级，而不是编造精确值？ |
| 2 竞品与友商对标 | 三种调研方法、三项对标、三维度、打法矩阵 | 如何把信息变成竞争策略？ |
| 3 全新市场 0→1 与间接开发 | 市场进入四步、客户三角倒逼、三方推进、两条增长轴 | 直接开发受阻时，还能怎样切入？ |
| 4 识别 KA 与渠道体系 | KA 三条件、distributor 与 agent、渠道权力与定价 | 哪些客户值得长期经营，渠道角色如何分工？ |
| 5 KA 终端开发四步法 | 组织架构、决策链、关键人、线人、coach、新人切入 | 怎样覆盖不同决策人的诉求？ |
| 6 客户经营与增量 | 站稳四做法、duplication、资源拓展、KA 动销 | 第一单之后怎样站稳并提高份额？ |
| 7 术语速查 | 29 个中英文业务术语 | 能否用业务场景解释术语？ |

知识地图提供「本章框架 → 小节目录 → 知识正文 → 我的便签」的阅读层次。公式、对比表、案例和连续原文都保留在页面内。

## 如何完成一次复习

建议用一个主题完成完整的一轮，而不是只浏览首页上的进度数字。

1. **读框架**：进入「知识地图」，先回答本章要解决什么问题。
2. **读小节**：结合公式、表格和案例理解具体方法。
3. **写便签**：在知识点下用自己的话写一句解释，或补一个工作场景。
4. **标记状态**：理解后标记「已学习」；不熟悉的内容保持未学习。
5. **主动回忆**：去闪卡页面，先在心里回答，再查看答案。
6. **检查理解**：做自测，答错后返回对应章节，再练错题。
7. **整合表达**：用口述训练串联知识，说明「怎么做、判断是什么、有什么价值」。

学习状态、闪卡掌握情况和题目答对情况分别记录。标记读完一章，不会自动把相关题目算作答对。

## 知识点便签与学习状态

### 写一张便签

在知识点下方点击「添加笔记」或「编辑笔记」，输入自己的理解，点击「完成编辑」后，文字会贴在该知识点正文下方。

输入时即写入浏览器本地存储。「完成编辑」用于收起编辑区域，不是唯一的保存动作。便签使用纯文本，保留换行；不提供富文本、图片上传或 Markdown 渲染。

每个知识点目前对应一张可反复修改的便签。章节末尾的「章节笔记」适合存放整章总结，原有章节笔记仍可继续使用。

### 标记学习状态

- 点击知识点的「未学习 · 标记完成」，把它设为已学习。
- 再次点击已学习标识，可撤销。
- 本章所有知识点完成后，章节状态同步完成。
- 在章节底部可将整章统一标为已学习，或撤销整章状态。

知识点新增后，不会仅因为旧版章节完成过就自动算作已学。

## 保存、备份与迁移

### 自动保存在哪里？

笔记、答题结果和学习进度保存在浏览器 `localStorage`。它们**不会写回 `app.js`、`data.js` 或仓库文件**。

保持同一浏览器、同一文件位置使用最方便。不同浏览器、不同设备、不同网页地址之间不会自动同步；本地文件路径改变后，能否读到原存储也取决于浏览器行为。

### 导出备份

点击右上角「导出学习记录」，保存生成的 `KA学习记录.json`。备份包含章节笔记、知识点便签、学习状态、答题记录及闪卡掌握状态。

导出的是**学习记录**，不是另一个包含个人笔记的网站安装包。网站文件和记录备份应分别保存。

### 导入到另一处

打开目标版本，点击「导入记录」，选择之前导出的 JSON 文件。

导入采用补入方式：

- 缺失的笔记和记录会加入。
- 已有非空同名笔记优先保留，不被导入内容覆盖。
- 已有答题和知识点状态优先保留；已完成章节列表会合并。
- 不提供冲突逐条比较、云同步或历史版本恢复。

如果希望使用备份中的较新笔记，而当前已有不同内容，可先保留双方导出文件，再手动复制所需文本，避免误以为导入会强制替换。

## 更新课程时保留旧笔记

1. 在旧版页面先「导出学习记录」。
2. 关闭旧页面，将新版运行文件覆盖到原文件夹。
3. 使用原浏览器打开同一路径的 `index.html`。
4. 检查章节笔记、便签与状态；若换了路径或浏览器，导入备份。

本次课程升级将原「术语速查」从第 6 章迁到第 7 章，同时新增「客户经营与增量」。版本内置了旧章号和小节名称映射，避免旧术语笔记落到新增章节。

已改名且可匹配的小节会关联旧便签。术语拆分、合并或未来再次大幅改写时，不保证每一条都能自动关联；更新前仍应保留备份。

## 上传到自己的 GitHub 仓库

先解压上传包，将里面的**全部项目文件**放到仓库根目录，再提交。仓库首页应能直接看到 `index.html` 和 `README.md`，而不只是一个 ZIP 文件。

别人通过 **Code → Download ZIP** 下载整个仓库，解压后双击 `index.html`，即可按本 README 的快速开始步骤使用。

仓库保存的是工具与课程内容，不包含每个使用者在浏览器中写下的笔记。个人导出的 `KA学习记录.json` 不属于需要上传的项目文件。

## 目录结构与内容维护

```text
项目根目录/
├── index.html       # 网页入口：导航、容器与资源引用
├── style.css        # 蓝色界面、响应式布局、状态与便签样式
├── app.js           # 学习交互、题目、摘要、保存与迁移逻辑
├── data.js          # 完整章节、结构化知识点、旧知识映射
├── 课程原文.md       # 课程内容来源，方便核对
├── 使用说明.txt      # 简短的本地使用与更新说明
└── README.md        # 完整项目说明
```

技术实现为原生 HTML、CSS 和 JavaScript，没有依赖安装和打包构建步骤。页面按顺序加载 `data.js` 与 `app.js`。

**维护内容时注意：**

- 只修改 `课程原文.md`，页面不会自动更新；页面读取的是 `data.js` 中的内置数据。
- `chapters` 保存连续章节，`knowledge` 保存小节与术语，`legacyKnowledge` 用于旧记录迁移。
- `app.js` 中还包含章节摘要、自测题及口述框架，更新课程时需要同步检查。
- 便签关联使用章节编号和知识点标题。改编号、标题或顺序时，应同时处理迁移映射。
- 不要随意更换学习记录的存储键，否则旧记录可能无法自动读到。

## 隐私与数据边界

- 应用运行不使用后端接口、统计脚本、在线字体或外部图片。
- 笔记保存在使用者自己的浏览器中，不会自动发送给作者或其他使用者。
- 不提供登录、跨设备同步、团队协作或远程备份。
- 导出的 JSON 含个人笔记，应当作自己的学习资料保管。
- 浏览器数据被清理且没有备份时，应用无法找回已删除记录。

## 常见问题

<details>
<summary>双击后没有样式，或页面空白怎么办？</summary>

先确认已经完整解压，且四个运行文件位于同一目录。不要只下载入口文件，不要在 GitHub 源码页或压缩包预览器中运行。使用正常允许 JavaScript 的浏览器打开。

</details>

<details>
<summary>为什么在新电脑打开后，旧笔记没有出现？</summary>

笔记存在原浏览器的存储中，不在网站源码里。请在原电脑导出学习记录，再在新电脑导入。仅复制项目文件不会自动携带个人记录。

</details>

<details>
<summary>能否只把一个 HTML 文件发给别人？</summary>

当前版本使用多个本地文件。请发送完整 ZIP 或文件夹，保留相对路径。对方完整解压后双击入口即可。

</details>

<details>
<summary>口述训练会自动评分吗？</summary>

不会。口述训练提供输入区和参考框架，供自行核对；没有录音、语音识别或 AI 评分。自测选择题则会显示正确答案和解释。

</details>

<details>
<summary>闪卡会根据遗忘曲线自动安排复习吗？</summary>

目前不会。闪卡记录掌握标记，支持顺序翻阅；没有间隔重复调度、每日提醒或随机出题机制。

</details>

<details>
<summary>笔记可以随便改，课程正文也能直接改吗？</summary>

页面提供个人笔记编辑，课程正文没有内置编辑器。修改课程需要编辑数据文件，并同步检查结构和练习。

</details>
