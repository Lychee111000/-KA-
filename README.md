# 知行 · KA 销售复习室（离线版）

课程更新至 11-24 第三课（S1–S3），共 8 个模块、40 个课程小节、29 个术语、20 道自测题与 5 道口述练习。

## 下载后直接使用

1. 在 GitHub 仓库页面选择 Code → Download ZIP。
2. 将下载的 ZIP 完整解压。
3. 双击解压文件夹内的 index.html，用 Edge 或 Chrome 打开。

无需安装依赖、无需命令行、无需启动服务器、无需登录或联网。所有样式、脚本和课程知识都包含在包内，不依赖 CDN 或在线接口。

## 功能

蓝色界面、知识目录与搜索、每个知识点的可编辑便签、显眼的已学习/未学习标记、章节笔记、闪卡、自测、错题回顾、口述训练，以及学习记录导入导出。

## 更新与笔记保留

先在旧版导出学习记录，再覆盖更新文件。保持原 index.html 路径并使用同一浏览器。
更换路径或浏览器时，可导入旧版导出的 JSON。当前已有的同名笔记不会被覆盖。
版本会迁移旧术语章笔记到第 7 章，并匹配改名的小节便签；新增知识点保持未学习。
学习记录仅在浏览器中保存，不会提交到仓库，也不与其他使用者共享。

## 文件结构

- index.html：双击打开的入口
- style.css：蓝色主题与便签样式
- app.js：学习交互与笔记保存
- data.js：完整课程、结构化知识点与旧版本迁移映射
- 课程原文.md：原始课程内容
- 使用说明.txt：本地使用说明

上传到 GitHub 时，将这些文件与 README.md 放在仓库根目录；不要只上传压缩包。保留文件的相对位置。

课程观点和算例按所提供文稿保留，未纳入后续课。站点不自动验证课程中的行业判断。
